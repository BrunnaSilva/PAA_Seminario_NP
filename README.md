## 🔭 Visão Geral

Dado um conjunto de números inteiros positivos S={s1,s2,...,sn} e um valor alvo T, o problema determina se existe algum subconjunto de S cuja soma é exatamente igual a T.

## 🚀 Como Usar

### Pré-requisitos
- Python 3.7 ou superior
- pip (gerenciador de pacotes do Python)

### Instalação das Dependências

1. **Clone o projeto:**
   ```bash
   git clone https://github.com/BrunnaSilva/PAA_Seminario_AGM.git
   cd PAA_Seminario_AGM
   ```

### Execução dos Algoritmos

#### Algoritmo recursivo
```bash
cd src/
python subset_sum.py
```

#### Algoritmo dinâmica
```bash
cd src/
python subset_sum_dp.py
```
